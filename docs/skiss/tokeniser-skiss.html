Data

      
Export, radering och inställningar

      
Dataraden ligger sist i vyn, eftersom radering inte går att ångra. Både export och radering bekräftas i VS Codes egna dialoger, inte i vyn. Din VS Code är på engelska, så knappen som avbryter heter Cancel; den läggs till av VS Code. Terminalraden stängs av med npm run connect -- --no-line och syns därför inte här.

    

    

      
Besvarat 15 sep 2026

      
Tre beslut om dataraden

      
    
        
  1. Raden visar antal händelser och storlek.
    2. 
        
  2. Raderingsdialogens texter räcker i båda lägena för Anslutning.
    3. 
        
  3. Rubriken i spara-dialogen märks inte, så aviseringen efter exporten säger vad filen innehåller. Den säger att bara du kan läsa filen bara om rättigheterna blev 0600. På en Windows-disk under /mnt, där 0600 inte gäller, säger den det i stället.
